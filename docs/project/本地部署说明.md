# openGym 本地部署

部署日期：2026-10-15。

## 版本与目录

- 官方源码：`upstream/`，固定为 `v1.4.1`。
- 源码提交：`464355ef43d4c8f8a4e0bb6db9c2af7f240593b5`。
- 镜像：官方 `opengym-api:1.4.1` 与 `opengym-web:1.4.1`，均为 ARM64，镜像提交与源码一致。
- 本地配置：`compose.yaml` 和 `.env`。
- 持久化数据：`data/`，保存账户、通行密钥、训练记录、会话密钥与上传素材。
- AI 提供商认证缓存：`coach-auth/`。
- 访问地址：[http://localhost:8080](http://localhost:8080)。端口仅绑定本机。

## 初次使用

1. 打开 Docker Desktop，等待引擎运行。
2. 在项目目录执行下方启动命令。
3. 打开访问地址，创建自己的个人资料并按浏览器提示完成通行密钥操作。
4. 首个注册账户会成为管理员，界面默认使用简体中文。

AI Coach 需要在管理员设置中启用并连接模型提供商，本次未配置模型凭据。
手机访问需要另外配置网络入口与 HTTPS；当前为 Mac 本机部署。

## 常用命令

在终端进入项目目录：

```bash
cd /Users/caixintan/Documents/ChatGPT/openGym
```

启动并等待健康检查：

```bash
docker compose up -d --wait --wait-timeout 90
```

查看状态和日志：

```bash
docker compose ps
docker compose logs --tail 100
curl -fsS http://localhost:8080/api/health
```

停止：

```bash
docker compose down
```

停止不会删除本地 `data/`。重新启动后继续使用原有数据。
Docker Desktop 正在运行时，容器采用 `unless-stopped` 重启策略。

## 数据备份

先停止服务，再备份完整数据目录和配置，最后重新启动：

```bash
docker compose down
mkdir -p backups
tar -czf "backups/opengym-$(date +%Y%m%d-%H%M%S).tar.gz" data .env compose.yaml
docker compose up -d --wait --wait-timeout 90
```

备份包含账户和会话密钥，应妥善保存。`coach-auth/` 不放入上述备份。
恢复时先停止服务并保留现有数据，再将选定备份解压回本项目目录，随后启动服务。
